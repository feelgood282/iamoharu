제미나이 Gems가 스킬로 바뀐다, 미리 할 일

작성 2026.10.26 · 기준일 2026년 10월 26일 · 구글 Gemini 앱 도움말 기준

핵심 요약
  1. 제미나이의 맞춤 도우미 Gems가 "스킬(skills)"로 바뀝니다. 개인 구글 계정은 2026년 11월 17일부터 Gems가 읽기 전용이 되고, 12월 17일에 Gems가 사라지면서 남은 Gem은 스킬로 자동 변환됩니다.
  2. 스킬은 대화창에 "/"를 입력해 불러오거나, 질문과 관련이 있으면 제미나이가 알아서 적용합니다. 한 대화에서 여러 스킬을 함께 쓸 수 있다는 점이 Gems와 가장 크게 다릅니다.
  3. 자동 변환 때 100MB를 넘는 파일, 오디오·영상, 예전 오피스 형식(.doc, .xls, .ppt), 압축 파일은 옮겨지지 않습니다. 12월 17일 전에 Gem의 지시문과 파일을 따로 저장해 두는 것이 안전합니다.

Gems와 스킬, 무엇이 달라지나

Gems는 자주 하는 일을 위해 지시문을 저장해 둔 나만의 제미나이였습니다. 스킬도 지시문 묶음이라는 점은 같지만, 쓰는 방식이 달라집니다. 구글 도움말에 따르면 스킬은 대화창이나 작업 칸에 "/"를 입력해 고를 수 있고, 활성화해 둔 스킬은 질문과 관련이 있을 때 제미나이가 알아서 적용합니다. 이때 제미나이는 먼저 스킬의 이름과 설명만 보고, 맞으면 전체 지시문을 읽고, 첨부 파일은 필요한 단계에서만 엽니다. 구글은 "/" 대신 "@"로 바뀔 예정이라고도 밝혔습니다.

SKILL.md는 다른 AI 도구에서도 쓰는 공개 형식이라, 한 번 만든 스킬을 다른 플랫폼과 주고받기 쉬워집니다. 공유 기능처럼 Gems에 있던 일부 기능은 스킬에도 넣을 예정이라고 했지만, 시기는 밝히지 않았습니다.

업무용·교육용 Workspace 계정은 남은 Gem이 "비활성 초안 스킬"로 바뀌고, 만든 사람이 하나씩 확인한 뒤 활성화해야 한다고 안내되어 있습니다. 이 노트는 개인 계정을 중심으로 정리했습니다. 한국어 계정이나 한국 지역에 따로 다른 일정이 있는지는 공식 페이지에서 확인하지 못했습니다(확인 필요).

자동 변환 때 빠지는 것

구글은 Gems가 삭제될 때 남은 Gem을 지원되는 파일과 함께 스킬로 자동 변환한다고 밝혔습니다. 다만 모든 것이 그대로 옮겨지지는 않습니다.

  • 용량: 스킬은 파일 전체가 100MB를 넘을 수 없습니다. Gem이 이보다 크면 가장 큰 파일부터 자동으로 빠집니다.
  • 옮겨지지 않는 파일: 깃허브 파일, 오디오, 영상, 예전 오피스 형식(.doc, .xls, .ppt), 압축 파일(.zip, .rar, .7z 등).
  • 스킬에서 아직 안 되는 기능: 영상 만들기, 음악 만들기, Canvas, Deep Research, Guided Learning. 이런 기능에 기대던 Gem은 스킬로 바뀐 뒤 같은 방식으로 움직이지 않을 수 있습니다.

스킬에 올릴 수 있는 파일은 일반 텍스트와 코드 파일(.txt, .md, .csv, .json, .html 등), .pdf, .jpg, .png입니다. .docx와 .xlsx는 지원하지 않으니, 워드나 엑셀로 된 자료는 PDF로 바꿔 두면 좋습니다.

지금 미리 할 일

  1. Gem 목록 정리: 실제로 쓰는 Gem과 안 쓰는 Gem을 나눕니다. 안 쓰는 Gem은 옮기지 않아도 됩니다.
  2. 지시문 복사: 쓰는 Gem의 이름, 설명, 지시문을 메모장이나 문서에 그대로 복사해 둡니다.
  3. 파일 내려받기: Gem에 올린 지식 파일을 모두 내려받습니다. 구글은 12월 17일 전에 내려받으라고 안내합니다.
  4. 직접 옮기기(선택): gemini.google.com에서 Customize(맞춤설정) → Skills 탭 → Create → Create manually를 고르고, 복사해 둔 이름·설명·지시문을 붙여 넣습니다.
  5. 만든 스킬 내려받기: Skills 페이지에서 스킬에 마우스를 올리고 More → Download를 누르면 SKILL.md가 든 .zip으로 저장됩니다. 이것이 가장 확실한 백업입니다.

스킬 이름은 영문 소문자와 하이픈으로 정해야 합니다(예: my-new-skill). 구글의 스킬 작성 안내는 "plan-meal-from-recipe"처럼 동사로 시작하고, 설명은 1~2문장(최대 1,024자)으로 "이럴 때 쓴다"는 예를 넣으라고 권합니다. 한 스킬에는 한 가지 일만 맡기는 편이 좋다고 합니다.

예) 이름: write-class-notice
설명: 피아노 레슨 수강생에게 보낼 안내 문자를 짧고 따뜻한 말투로 쓴다.
     수업 일정 변경, 준비물 안내, 연습 과제를 알릴 때 사용한다.
누가 쓸 수 있나 2026년 10월 기준으로 스킬은 만 18세 이상이 개인 구글 계정으로 로그인하고 활동 기록 저장(Keep Activity)을 켜 둔 경우 쓸 수 있습니다. 유료 구독은 필요 없고, 제미나이 웹·모바일 앱·Mac 앱에서 쓸 수 있습니다. 파일을 올려 스킬을 만드는 기능은 지금은 웹과 Mac 앱에서만 됩니다. 활성 스킬은 최대 100개입니다.

제미나이 스킬 전환 체크리스트

  • 내가 쓰는 Gem 목록을 확인했다
  • Gem마다 이름·설명·지시문을 문서로 복사해 두었다
  • Gem의 지식 파일을 12월 17일 전에 내려받았다
  • .docx·.xlsx·오디오·영상 파일은 PDF나 텍스트로 바꿔 두었다
  • 자주 쓰는 Gem 하나를 직접 스킬로 만들어 "/"로 불러 보았다
  • 만든 스킬을 .zip으로 내려받아 백업했다
